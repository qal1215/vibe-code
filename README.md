# Vibe Code

A standalone catalog of apps built by Anh Le. This repository is separate from qal.vn.

## Included apps

- Gamepad Bench
- Pixelio
- LAN Share

The app catalog lives in `src/apps.ts`. Only verified public URLs are linked; the other projects are shown without demo links.

## Develop

```sh
pnpm install
pnpm dev
```

## Verify

```sh
pnpm lint
pnpm build
```

Built with React, TypeScript, Vite, Tailwind CSS, and Unhead.
